#SHUD - StreamHUD

SHUD — это десктопное приложение для работы с киберспортивными HUD‑ами и оверлеями: команды, игроки, матчи, синхронизация с OBS и управление сценами в один клик. Запуск приложения осуществляется через скомпилированный .exe‑файл.
Расширенное описание
SHUD — это удобная оболочка для управления трансляциями и оверлеями:
Управление командами и игроками: создание, редактирование и импорт/экспорт баз команд и игроков, в том числе с логотипами и флагами стран.
Матчи и HUD‑ы: настройка матчей (формат, команды, карты), выбор и конфигурирование HUD‑пакетов для разных игр.
Интеграция с OBS: для работы с камерами игроков.
Локальное хранение данных: все настройки и базы хранятся локально в папке приложения, без облака.
Приложение поставляется в виде исполняемого файла Windows, запуск производится через .exe, без необходимости вручную устанавливать Node.js или запускать скрипты из консоли.

SHUD is a desktop application for managing esports HUDs and overlays: teams, players, matches, OBS synchronization, and one-click scene management. The application is launched via a compiled .exe file.
Extended Description
SHUD is a convenient shell for managing broadcasts and overlays:
Team and Player Management: Create, edit, and import/export team and player databases, including logos and country flags.
Matches and HUDs: Match settings (format, teams, maps), select and configure HUD packages for different games.
OBS integration: for working with player cameras.
Local data storage: All settings and databases are stored locally in the application folder, without the need for cloud storage.
The application is delivered as a Windows executable file and launched via the .exe file, eliminating the need to manually install Node.js or run scripts from the console.
